### FAQ

**Do I need to know how to code?**
No. These are import-and-configure. Click buttons, add your API key, done.

**Which AI model should I use?**
Claude (best quality), GPT-4 (most popular), or DeepSeek (cheapest, great for Chinese). Any OpenAI-compatible API works.

**Does n8n cost money?**
No. n8n is free and open-source when self-hosted. You only pay for the AI API calls (typically $0.01-0.05 per workflow execution).

**Can I use these for my clients?**
Yes. You can deploy these templates for your clients as part of your own service. Many agencies use these as a starting point.

**What if I need help?**
Email support is included. If you need custom automation built, that's available separately.
